# InnerVoice — React Router Connected Project

Merged from the two supplied ZIP files.

Connected flow:
Welcome → Login → InnerVoice Home

Forgot Password → Verify Email / OTP → Reset Password → Login

Frontend-only: no MongoDB, Express, or API. Authentication state uses sessionStorage for route protection. OTP/password verification is UI-only because there is no backend.

Run:
```bash
npm install
npm run dev
```
